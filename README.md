# 🍗 갓슴살 AI 코치 (Gatseumsal AI Coach)

> 운동 기록을 입력하면, 닭가슴살 캐릭터가 **약점을 분석해서 코멘트**해주는 Python 프로그램입니다.
> "약골 닭가슴살을 운동으로 갓슴살로 키운다"는 컨셉의 운동 기록 앱 아이디어를, 핵심 로직만 미니 버전으로 구현했습니다.

---

## 📌 무엇을 하는 프로그램인가요?

1. 하루 운동 기록(동작·분류·값·단위)을 받아서
2. **분류별 운동량을 집계**하고 (맨몸 / 바벨 / 유산소 …)
3. **가장 부족한 분류(약점)를 찾아낸 뒤**
4. 닭가슴살 캐릭터가 **열혈 츤데레 스타일로 코멘트**해 줍니다.

이름 호칭도 한국어 문법에 맞게 자동 처리합니다. (받침 있으면 "주한**아**", 없으면 "민지**야**")

---

## 🖥️ 실행 결과 예시

```
=============================================
🍗 갓슴살 AI 코치 — 오늘의 운동 분석
=============================================

[오늘 한 운동]
  - 풀업(맨몸): 30회
  - 푸시업(맨몸): 50회
  - 데드리프트(바벨): 100kg
  - 스쿼트(바벨): 80kg
  - 러닝(유산소): 2000m

[분류별 운동 횟수]
  맨몸   | ■■ 2개
  바벨   | ■■ 2개
  유산소  | ■ 1개

[🍗 닭가슴살 코치의 한마디]
"주한아, 오늘 운동 5개나 했네! 👀
  근데 '유산소' 운동이 제일 부족해. 근력도 키워야 균형 잡힌 갓슴살이지!
  '맨몸'은 잘하고 있으니까... 흥, 계속 그렇게 해."
```

## 🛠️ 사용 기술

- **Python 3** — 데이터 처리(리스트·딕셔너리), 함수 설계, 한글 문자열 처리
- **Anthropic Claude API (LLM)** — 캐릭터 코멘트를 AI로 생성 (선택 기능)

## ✨ 핵심 기능

| 기능 | 설명 |
|---|---|
| 운동 기록 집계 | 분류별로 운동 횟수를 세어 막대그래프로 표시 |
| 약점 분석 | 가장 적게 한 운동 분류를 자동으로 탐지 |
| 한국어 호칭 처리 | 이름 끝 받침을 계산해 '아/야' 자동 선택 |
| AI 코멘트 (LLM) | Claude API로 상황에 맞는 캐릭터 코멘트 생성 |
| 안전한 대체 동작 | API 키가 없으면 규칙 기반 코멘트로 자동 전환 |

---

## ▶️ 실행 방법

```bash
# 1. (선택) AI 기능을 쓰려면 Claude API 라이브러리 설치
pip install anthropic

# 2. (선택) AI 기능용 API 키 등록 — 없으면 규칙 기반으로 동작
#    Windows PowerShell:
$env:ANTHROPIC_API_KEY="여기에-API-키"

# 3. 실행
python main.py
```

> API 키가 없어도 프로그램은 정상 동작합니다. (규칙 기반 코멘트로 자동 전환)

## 💡 만들면서 배운 것

- 데이터를 분류·집계해서 **의미 있는 결론(약점)을 뽑아내는** 로직 설계
- LLM(Claude) API를 실제 프로그램에 연결하고, **키가 없을 때의 대체 동작**까지 고려한 구조
- 한글 유니코드(받침) 계산 등 **언어에 맞는 디테일** 처리
